# CONFIG checklist

Before first use, open `producer-song-memory-agent.md` and replace these four placeholders.
Everywhere `[NAME]` appears (three places), use the producer's name.

- [ ] **Producer name** — replaces every `[NAME]`.
      Example: `Tobi`

- [ ] **Storage locations in use** — every place tracks actually live, with the label the
      agent should use when recording a location. Be exact; the agent will never invent one.
      Example:
      `"Laptop SSD - D:/Music", "External HDD - E:/Archive", "Google Drive - /Beats2026"`

- [ ] **Genres/moods you tag with** — the vocabulary the producer uses for `genre_mood`.
      Example:
      `Afrobeats, Amapiano, Trap, R&B, Sad, Club`

- [ ] **DAW** — used to read project/session context.
      Example: `FL Studio`

That's the whole setup. Everything else in the prompt works as written.
